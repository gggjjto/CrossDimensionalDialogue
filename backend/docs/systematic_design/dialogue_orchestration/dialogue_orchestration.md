# 对话编排 MVP 设计

## 概述

对话编排是AI角色扮演平台的核心组件，负责将用户输入、角色persona、历史消息组合起来，动态构建prompt，并调用LLM生成角色回复。

## 当前实现状态

### ✅ 已实现功能
- **会话管理**: 完整的CRUD操作，支持会话创建、查询、更新
- **消息管理**: 消息存储、查询、实时传输
- **WebSocket通信**: 实时消息推送和状态管理
- **语音服务**: STT/TTS服务集成
- **向量搜索**: 角色搜索和嵌入生成
- **权限控制**: 用户认证和限流机制

### 🚧 待实现功能（MVP优先级）
1. **LLM集成服务** - 调用大语言模型生成回复
2. **基础上下文拼接** - 简单的prompt构建
3. **消息流控制** - 用户消息到角色回复的完整流程

## MVP核心功能

### 1. 基础上下文拼接
- 获取角色persona（系统提示词）
- 获取最近N条会话历史
- 拼接用户输入
- 构建完整的prompt

### 2. LLM调用服务
- 集成OpenAI或其他LLM服务
- 发送prompt获取角色回复
- 处理LLM响应和错误

### 3. 消息流控制
- 用户发送消息 → 构建prompt → 调用LLM → 生成角色回复
- 可选：调用TTS生成语音回复
- 保存消息到数据库

## 技术实现要点

### 数据模型
- 复用现有的`conversations`和`messages`表
- 添加`conversation_settings`表存储LLM配置

### API接口
- `POST /api/v1/conversations/{id}/send-message` - 发送消息并获取角色回复
- `GET /api/v1/conversations/{id}/context` - 获取当前上下文

### 服务架构
```
用户消息 → 会话服务 → LLM服务 → 角色回复 → 消息存储
```

## 实现优先级

### 第一阶段：基础LLM集成
1. 创建LLM服务类
2. 实现基础prompt构建
3. 集成到消息发送流程

### 第二阶段：上下文优化
1. 实现上下文窗口管理
2. 添加角色persona动态加载
3. 优化prompt模板

### 第三阶段：高级功能（当前阶段）
1. **多角色支持** - 多角色对话和角色切换
2. **RAG知识注入** - 外部知识库检索增强
3. **高级策略调度** - 智能上下文管理和摘要
4. **智能上下文管理** - 动态上下文窗口和摘要生成
5. **角色切换机制** - 基于上下文的智能角色选择
6. **知识库服务** - 向量检索和知识融合
